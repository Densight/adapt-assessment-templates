# ADAPT Assessment Templates

**Densight Labs - Applied AI. Not just talked about.**

Ready-to-use templates for evaluating enterprise AI readiness across the five dimensions of the ADAPT Framework's Assessment phase.

## What Is Inside

- AI readiness scorecards for data infrastructure, talent, process, technology, and culture
- Stakeholder interview guides and workshop facilitation templates
- Gap analysis frameworks with prioritization matrices

## ADAPT Phase

These templates support the **Assess** phase, helping organizations evaluate their current state before AI implementation.

### Template Example: Data Infrastructure Assessment

**Use case:** Evaluate data quality and accessibility for AI initiatives.

- Data source inventory
- Quality metrics (completeness, accuracy, timeliness)
- Governance maturity level
- Integration complexity score
- Storage and compute capacity

**Example:** Customer database | 85% complete, 92% accurate | Basic governance | Medium complexity | 500GB, scalable cloud
